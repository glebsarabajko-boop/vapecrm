# Запуск VapeCRM — инструкция

## 1. Без установки: готовое приложение

Приложение уже развёрнуто и работает — просто открой ссылку:

**https://vape-crm-ury1.zai-ai.site**

Вход:
- **Владелец** — `admin` / `admin123`
- **Мастер** — `master` / `master123`
- **Клиент** — свой телефон + пароль (создаётся при записи на `/book` или через `/cabinet/register`)

### Установить как приложение (PWA)

| Устройство | Шаги |
|---|---|
| **Android (Chrome)** | Меню ⋮ → «Установить приложение» → иконка на рабочем столе |
| **iPhone (Safari)** | «Поделиться» → «На экран “Домой”» → «Добавить» |
| **Компьютер (Chrome/Edge)** | Значок ⊕ в адресной строке → «Установить» |

Установленное приложение открывается без адресной строки и берёт данные с сервера —
ничего не хранится на телефоне.

## 2. Локальный запуск (свой экземпляр для разработки)

Нужен **Node.js 22.6 или новее** (проверить: `node -v`).

**Терминал 1 — приложение:**

```bash
cd путь/к/проекту
npm install        # первый раз только
npm run db:init    # первый раз только: создаст базу + демо-данные
npm run dev        # → http://localhost:3000
```

**Терминал 2 — Telegram-бот (необязательно):**

```bash
cd путь/к/проекту
npm run bot        # нужен токен в .env (см. ниже)
```

⚠️ Бот стартует **автоматически вместе с приложением** — отдельный `npm run bot`
нужен только если запускаешь бота без приложения. Два бота одновременно конфликтуют.

## 3. Telegram-бот: токен

1. В Telegram: **@BotFather** → `/newbot` → придумай имя и адрес → получи токен
   (строка вида `123456789:AAH...`)
2. Вставь его в файл `.env` проекта:
   ```
   TELEGRAM_BOT_TOKEN="твой-токен"
   ```
3. Запусти бота (автоматически с приложением, или отдельно `npm run bot`)
4. Клиент пишет боту `/start` и свой номер → бот привязывает чат →
   уведомления о готовности ремонта и напоминания о картридже приходят сами

⚠️ Токен — пароль бота: не публикуй его. Утёк — BotFather → `/revoke`.

## 4. Частые проблемы

| Проблема | Решение |
|---|---|
| Порт 3000 занят | Где-то запущен второй `npm run dev` — найди и останови его, иначе Next уйдёт на порт 3001 |
| Бот отвечает «ошибка 409» | Запущены два бота одновременно — останови лишний (`Ctrl+C` или через диспетчер задач) |
| Бот «не отвечает» | Проверь, что процесс запущен и токен в `.env`; перезапусти |
| Склад опустел (товары «нет в наличии») | `node scripts/reset-stock.mjs` — вернёт демо-остатки |
| Забыл пароль клиента | Сбрось через базу (SQLite) или пересоздай кабинет |
| Ничего не появляется в списке | Обнови страницу (F5) — списки рисуются при запросе; страница ремонтов обновляется сама раз в 20 секунд |
| Хочу чистую демо-базу | Удали `db/data.db` → `npm run db:init` |

## 5. Обновление уже развёрнутого проекта

```bash
git pull
npm install        # если менялись зависимости
npx prisma db push # если менялась схема
npm run dev
```

## 6. Прод-сборка и деплой (ZCode Sites)

```bash
npm run build
node scripts/zcode-site.mjs deploy .zcode-site/stage   # см. README проекта
```

Сборка создаёт самодостаточный `standalone`-вариант: `node .next/standalone/server.js`
с переменными `DATABASE_URL` (файл БД в `$DATA_DIR`) и `PORT=3000`. Telegram-бот на
проде требует токена в окружении сервера.
